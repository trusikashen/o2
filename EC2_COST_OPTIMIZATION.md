# Гайд по оптимизации стоимости EC2 Windows

## 💰 Текущая цена (c6i.4xlarge Windows)

**On-Demand:** $1.416/час = **$1 019/месяц**

---

## 🎯 Стратегии оптимизации затрат

### Вариант 1: Reserved Instances (лучше всего для 24/7)

**Резерв на 1 год:**
- **Цена:** ~$300-400/месяц (экономия 60-70%)
- **Итого:** ~$3 600-4 800/год
- **Подходит для:** постоянного продакшена

**Резерв на 3 года:**
- **Цена:** ~$250-350/месяц (экономия 75-80%)
- **Итого:** ~$9 000-12 600/3 года
- **Подходит для:** долгосрочного использования

**Как купить:**
1. EC2 Console → Reserved Instances → Purchase Reserved Instances
2. Выбрать: `c6i.4xlarge`, Windows, срок 1 год
3. Оплата: полностью upfront (максимальная скидка) или частично upfront

---

### Вариант 2: Savings Plans (гибко)

**Compute Savings Plan:**
- **Цена:** ~$400-500/месяц (экономия 50-60%)
- **Гибкость:** можно менять типы/семейства инстансов
- **Подходит:** если возможна смена типов

**EC2 Instance Savings Plan:**
- **Цена:** ~$350-450/месяц (экономия 60-65%)
- **Гибкость:** только то же семейство
- **Подходит:** фиксированный тип инстанса

---

### Вариант 3: Spot Instances (дешево, но риск)

**Цена:** ~$400-600/месяц (экономия 40-60%)

**Риски:**
- могут прерваться (terminate) с предупреждением за 2 минуты
- не для продакшена 24/7
- нужно уметь обрабатывать прерывания

**Подходит для:**
- некритичных задач
- если можно терпеть прерывания
- если есть запасной воркер (например, на DigitalOcean)

---

### Вариант 4: По расписанию (старт/стоп)

**Работа 12 часов/день:**
- **Цена:** $1.416/час × 12ч × 30 дней = **$510/месяц** (экономия 50%)

**Работа 8 часов/день:**
- **Цена:** $1.416/час × 8ч × 30 дней = **$340/месяц** (экономия 67%)

**Автоматизация:**
- AWS Lambda + EventBridge для старта/остановки по расписанию
- Воркер автозапускается при старте инстанса (PM2 настроен)

**Подходит для:**
- только рабочие часы
- можно планировать относительно пиков

---

### Вариант 5: Меньший инстанс (если конкурентность < 25)

**c6i.2xlarge (8 vCPU, 16GB RAM):**
- **On-Demand:** ~$0.708/час = **$510/месяц**
- **Reserved (1 год):** ~$150-200/месяц
- **Подходит для:** 10-15 одновременных браузеров

**c6i.xlarge (4 vCPU, 8GB RAM):**
- **On-Demand:** ~$0.354/час = **$255/месяц**
- **Reserved (1 год):** ~$75-100/месяц
- **Подходит для:** 5-8 одновременных браузеров

## 🎯 Рекомендованная стратегия

### Для продакшена (24/7):

**Лучший вариант:** Reserved на 1 год
- **Цена:** ~$300-400/месяц
- **Экономия:** $600-700/месяц vs on-demand
- **Настройка:** покупка один раз, дальше работает 24/7

### Для теста/разработки:

**Лучший вариант:** On-Demand + расписание
- **Цена:** $340-510/месяц (8-12ч/день)
- **Гибкость:** можно менять расписание
- **Настройка:** Lambda для автозапуска/остановки

### Если важна экономия:

**Лучший вариант:** c6i.2xlarge Reserved (1 год)
- **Цена:** ~$150-200/месяц
- **Компромисс:** ниже конкурентность (10-15 браузеров)
- **Настройка:** выставить `MAX_CONCURRENT_BROWSERS=15` в .env

## 🔧 Как настроить Reserved Instance

1. **EC2 Console** → **Reserved Instances** → **Purchase Reserved Instances**

2. **Configure:**
   - **Platform:** Windows
   - **Instance Type:** c6i.4xlarge
   - **Term:** 1 year (или 3 года)
   - **Payment:** All upfront (лучшая скидка)

3. **Review & Purchase**

4. **After purchase:**
   - Резерв применяется автоматически
   - Код менять не нужно
   - Тот же инстанс, меньшая цена

---

## 🔧 Как настроить работу по расписанию (старт/стоп)

### Через AWS Lambda + EventBridge:

1. **Create Lambda function** to start/stop instance:
   ```python
   import boto3
   
   ec2 = boto3.client('ec2')
   INSTANCE_ID = 'i-xxxxxxxxxxxxx'
   
   def start_instance():
       ec2.start_instances(InstanceIds=[INSTANCE_ID])
   
   def stop_instance():
       ec2.stop_instances(InstanceIds=[INSTANCE_ID])
   ```

2. **Create EventBridge rules:**
   - **Start:** каждый день в 8:00 AM UTC
   - **Stop:** каждый день в 8:00 PM UTC

3. **Configure PM2 auto-start:**
   - PM2 уже настроен на автозапуск при старте
   - При запуске инстанса PM2 автозапустит воркер
