# Система бота для Adsterra Smart Link

Автоматизированная система ботов для генерации показов по Smart Link от Adsterra.

## 🎯 Обзор

- **Цель:** 160 000 показов/день
- **Боты:** 16 000 ботов × 10 сессий каждый
- **Прокси:** IPRoyal Mobile Proxies
- **Расход:** $10.11/день
- **Ожидаемый профит:** $230.89/день

4. **AWS-креды** — задать в `.env`

## 🚀 Установка

1. **Установите зависимости:**
   ```bash
   cd adsterra
   npm install
   ```

2. **Настройте окружение:**
   ```bash
   cp env.template .env
   # Отредактируйте .env (особенно BLOG_HOMEPAGE_URL)
   ```

3. **Обновите .env:**
   - Задайте `BLOG_HOMEPAGE_URL` на ваш блог
   - При необходимости скорректируйте `TOTAL_BOTS` и `SESSIONS_PER_BOT`
   - Поставьте `BROWSER_HEADLESS=false` для теста (видеть браузер)

## 🏃 Запуск

### 1. Создать таблицы DynamoDB (однократно)
```bash
# Создать таблицу для задач (jobs)
npm run setup:jobs

# Создать таблицу для прогонов (runs)
npm run setup:runs

# Создать таблицу для конфигурации воркеров (Phase 2 - конфигурация)
npm run setup:workers-config
```

### 2. Запустить фронтенд + админ панель
```bash
npm run dev
```
Откроется на `http://localhost:3000`

### 3. Настроить конфигурацию воркеров (новое в Phase 2!)
```bash
# 1. Перейдите на: http://localhost:3000/admin/workers
# 2. Каждый из 15 воркеров может иметь:
#    - Уникальный Smart Link URL
#    - Индивидуальные настройки тайминга
#    - Собственные параметры браузера
#
# Пример конфигураций:
# worker-0:  https://example.com/campaign-A
# worker-1:  https://example.com/campaign-B
# worker-5:  https://example.com/campaign-C
```

### 4. Создать кампанию
```bash
# 1. Перейдите на: http://localhost:3000/adsterra
# 2. Создайте новую кампанию
# 3. Выберите воркеров: worker-0, worker-5, worker-12
# 4. Работы будут распределены round-robin между выбранными воркерами
# 5. Каждый воркер будет использовать свой Smart Link и настройки
```

### 5. Запустить воркеры
```bash
npm run worker
```
Запустите несколько воркеров (в разных терминалах) для скорости:
```bash
# Терминал 1
npm run worker

# Терминал 2
npm run worker

# Терминал 3
npm run worker
```

### 4. Мониторинг (опционально)
```bash
npm run dev
```
Показывает статистику очереди в реальном времени.

## 📊 Поток выполнения

Каждая сессия бота:
1. Заходит на главную блога
2. Собирает все статьи на главной
3. Рандомно выбирает статью
4. Переходит на статью
5. Скроллит вниз до Smart Link
6. Кликает Smart Link
7. Ждет 20-60 секунд на странице рекламодателя (для показа)
8. Закрывает браузер

## ⚙️ Конфигурация

### Переменные окружения

- `BLOG_HOMEPAGE_URL` — URL главной страницы
- `SMART_LINK_TEXT` — текст Smart Link
- `TOTAL_BOTS` — число ботов (по умолчанию 16000)
- `SESSIONS_PER_BOT` — сессий на бота в день (по умолчанию 10)
- `BROWSER_HEADLESS` — true для продакшена, false для теста
- `REDIS_URL` — URL подключения Redis

### Тайминги

- `MIN_SCROLL_WAIT` — минимум ожидания после скролла (мс)
- `MAX_SCROLL_WAIT` — максимум ожидания после скролла (мс)
- `MIN_AD_WAIT` — минимум ожидания на рекламе (мс) — 20 секунд
- `MAX_AD_WAIT` — максимум ожидания на рекламе (мс) — 60 секунд

## 🔍 Тестирование

1. Поставьте `BROWSER_HEADLESS=false` в `.env`
2. `TOTAL_BOTS=10` и `SESSIONS_PER_BOT=1` для теста
3. Запустите orchestrator для создания тестовых задач
4. Запустите worker, чтобы увидеть браузер
5. Убедитесь, что Smart Link находится и кликается верно

## 📈 Мониторинг

- Статус очереди: смотрите Redis или скрипт мониторинга
- Успех: сравнивайте выполненные/упавшие задачи
- Дашборд Adsterra: проверяйте показы в аккаунте

## ⚠️ Важные заметки

- Каждый бот получает уникальный IP из IPRoyal автоматически
- Сессии распределены по 24 часам
- Средняя конкурентность: ~75-100
- Пиковая конкурентность: ~200-300
- Каждая сессия = новый браузер = новый IP

## 🛠️ Траблшутинг

### Smart Link не найден
- Проверьте, что `SMART_LINK_TEXT` совпадает точно
- Убедитесь, что ссылка есть на страницах статей
- Проверьте селекторы статей в `src/bot/session.ts`

### Нет статей
- Обновите селекторы статей в `findArticles()`
- Проверьте структуру главной страницы
- Убедитесь, что `BLOG_HOMEPAGE_URL` корректен

### Очередь не обрабатывается
- Проверьте, что Redis запущен
- Проверьте `REDIS_URL`
- Посмотрите логи воркера на ошибки
