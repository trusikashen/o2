# SSH Terminal Setup Guide

## Автоматическое подключение к AWS VM

Терминал теперь автоматически подключается к вашей AWS машине при открытии модального окна.

### Конфигурация

В файле `.env` установлены следующие параметры для автоматического подключения:

```dotenv
SSH_VM_IP=100.48.93.18          # IP адрес AWS VM
SSH_USERNAME=ubuntu              # Пользователь SSH (по умолчанию ubuntu)
SSH_KEY_PATH=./a.pem             # Путь к SSH ключу относительно корня проекта
```

### Как использовать

1. **Откройте страницу Adsterra** - перейдите на `http://localhost:3001/adsterra`

2. **Кликните кнопку "🖥️ Terminal"** в верхней панели (рядом с кнопками "☀️" и "⚙️ ENV")

3. **Терминал откроется и автоматически подключится** к AWS машине:
   - Подключение устанавливается автоматически
   - Используются учётные данные из `.env` файла
   - SSH ключ загружается из `a.pem` в корне проекта

4. **Выполняйте команды** в открытом терминале:
   - Введите команду в поле ввода внизу
   - Нажмите Enter или кликните кнопку "Send"
   - Результат появится в терминале в реальном времени

5. **Закройте терминал** - кликните кнопку X в верхнем правом углу модального окна

### Примеры команд

```bash
# Проверить текущую директорию
pwd

# Список файлов

# Проверить статус процессов
ps aux | grep node

# Проверить использование памяти и диска
df -h

# Проверить логи вашего приложения
journalctl -u your-app-service -f

# Выполнить docker команду

```

### Требования

- `a.pem` файл должен находиться в корне проекта
- `.env` переменные должны быть правильно установлены
- AWS VM должна быть доступна по сети
- SSH порт (22) должен быть открыт на AWS машине

### Отладка

Если подключение не работает:

1. **Проверьте IP адрес** - убедитесь что `SSH_VM_IP=100.48.93.18` в `.env` корректен
2. **Проверьте SSH ключ** - убедитесь что `a.pem` находится в корне и имеет правильные разрешения
3. **Проверьте доступность VM** - пингуйте IP из вашей машины
4. **Посмотрите логи браузера** - откройте DevTools (F12) и проверьте Console

### WebSocket архитектура

Терминал работает через:
- **Frontend**: React компонент с xterm.js
- **Backend**: Next.js API с SSH2 поддержкой  
- **Real-time**: HTTP запросы (WebSocket готов к добавлению)

Полная архитектура WebSocket для остальной системы находится в `/src/lib/socket-server.ts`.

### Безопасность

⚠️ **Важно**: Текущая реализация НЕ имеет аутентификации. Используйте только в локальной сети или за VPN!

Для продакшена рекомендуется:
- Добавить аутентификацию пользователя
- Использовать IAM роли вместо raw credentials
- Шифровать передачу данных
- Ограничить список доступных команд
